# video-art: review and the anti-list

## How art is reviewed
- **One image at a time**, 2000 px wide, with a label. A set of variants is allowed only when they are the same subject, numbered 1..N, and the user picks by number. Keep the last round's sheet beside the new one.
- **Check the thing that was complained about first**, then everything else. State what changed, in one line, per image.
- **Measure, then look:** a vision pass on the rig alone (face, hands, feet), a zoom crop for hands and edges, numeric ratios (hand/wrist, prop/person).
- **List your own five weakest spots** before the user does, with the fix or the reason it stays.
- **Never ship a variant you would reject.** If an option fails a rule, say so and drop it.
- **Denis's vocabulary:** "chaotic lines" = too many, jittery edges; "glitch / corners" = join artifacts; "3D" = layered soft shading; "circles too apparent" = round shapes read as geometry; "weird" = a part that fights the role; "too basic" = ask for a variation, not a restart; "needs detail" = story-telling details (a calendar, a sticky note with a warning, fridge items) not more decoration.
- **A number picked is a decision.** "Number 3 but ..." means keep 3 and apply the "but"; "settled, num 1" means freeze.
- Order of work for a character: look study (many looks) -> pick -> role correction -> expressions -> mouths -> body/poses -> freeze -> commit.
- Freeze when the user says so; "continue / keep refining" means a new round, not a version.

## Anti-list: looks that read as AI template
(From an outside creator's list plus our own rejections. Any hit is a defect.)
- gradient backgrounds, purple/neon glow, glass, floating particles;
- glossy or 3D rendering, soft layered shading, any 3D feel in a 2D style;
- everything sliding up at once; a constant zoom pulse; a whoosh on every cut;
- stick figures on an empty background; a hero who looks different in each scene;
- letters inside generated pictures; a label that explains a picture the picture should explain;
- a table (or any big object) dead centre of a dialogue frame;
- full-screen pasted text with no composition;
- circles and thin stripes as decoration; chaotic outlines;
- decoration with no line pointing at it;
- a character holding a prop for no reason;
- rig stand-ins (any generic figure for a missing rig).

## What was praised (keep doing)
- detail that tells the story and is quiet: a calendar, a sticky note with a warning, fridge notes;
- a recognisable old computer with a name;
- a character look that carries the job at a glance;
- eyes that show the feeling (loving, hating the world) at close-up size;
- wall text as the room's one joke.
